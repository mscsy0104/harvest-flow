# Code of Conduct

This project follows the Contributor Covenant Code of Conduct.

## Our Pledge

We pledge to make participation in this project a harassment-free experience for everyone.

## Our Standards

- Be respectful and constructive.
- Assume good intent; ask for clarification before escalating.
- Focus feedback on code, behavior, and outcomes.

## Enforcement

Report unacceptable behavior by opening a private security report or contacting maintainers listed in `SECURITY.md`.
