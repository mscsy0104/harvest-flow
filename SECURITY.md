# Security Policy

## Supported Versions

Security fixes are provided for the latest release line.

## Reporting a Vulnerability

Please do not open public issues for security vulnerabilities.

1. Send a private report to project maintainers.
2. Include reproduction steps, impacted version, and potential impact.
3. Allow reasonable time for triage and patching before disclosure.

## Disclosure Process

- We acknowledge reports quickly.
- We validate impact and prepare a fix.
- We publish release notes after remediation.
